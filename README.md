# Readmissions Power BI Dashboard

Complete project by Chigozie Nkwopara.

## Download the project

[Download the full project source](readmissions-powerbi-source.zip). Extract the ZIP into a folder named `readmissions-powerbi`. The archive contains the complete source, documentation and original folder structure.

Read `README.md` inside the extracted folder for setup and use.

Native Power BI project with seven report pages, DAX measures, aggregate data, previews and local data preparation.

Run the [analysis project](https://github.com/Ghenomenon/readmissions-case-study) first, then follow the archive README to prepare local patient data and open the `.pbip` file directly in Power BI Desktop.

The public package excludes patient-level records. This is an exploratory portfolio prototype.
